# DESS66 benchmark data

This directory vendors the unmodified `DESS66.zip` archive from:

- DOI: https://doi.org/10.5281/zenodo.5676284
- Version: 1.0.0 (2021-02-10)
- Zenodo record: https://zenodo.org/records/5676284

Checksums:

- SHA-256: `99e23bbcf0276a9a364cffa5c7d471242020ef699c2e17889183cf59bfc8f65e`
- MD5 published by Zenodo: `48930e4d01b0844b2c0c1fd2db7cc16b`

`LICENSE.txt` is reproduced alongside the archive so the DESRES redistribution
notice remains visible. The same notice is also present inside `DESS66.zip`.

The tutorial reads the CSV directly from the ZIP. It uses four equilibrium
dimers and their frozen monomers; no coordinates or reference energies are
rewritten by hand.
