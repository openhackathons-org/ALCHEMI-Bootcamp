# NCI Atlas tutorial subset

`nci-atlas-curves.csv.gz` contains 90 frozen-geometry records used by Part 03:
three complexes, ten separation points, and `AB`, `A`, and `B` at each point.
It includes absolute ωB97M-D3(BJ)/def2-TZVPPD energies and CCSD(T)/CBS
interaction-energy references.

Source: [NCI Atlas](https://github.com/Honza-R/NCIAtlas) at revision
`1816bfc72609d7deb1d4f93ab9e27eb13bb44bec`. The tutorial file is a selected,
reformatted subset generated by `scripts/prepare_nci_subset.py`; source row and
geometry identifiers are retained. The builder requires a clean Git checkout
at that exact revision before reading the source files.

SHA-256: `7ffbc071e2998cee8e487a2697517187110a05f436920f8611d28d2af5d4d7b7`

## Organic IR molecule library

`ir-molecule-library.extxyz` contains 32 distinct neutral H/C/N/O fragments
from the same exact NCI Atlas revision. The molecules span 4–20 atoms and 322
atoms total. Every graph is a different molecule; the file contains no copied
structures.

`ir-molecule-library-manifest.json` records each learner-facing label, source
label, formula, atom count, formal charge, source dataset, system ID, geometry
file, selected fragment, block index, and SHA-256 values. It also records the
repository URL, exact revision, and CC BY 4.0 license.

The deterministic builder is `scripts/prepare_nci_ir_molecules.py`. It requires
a clean NCI Atlas checkout at revision
`1816bfc72609d7deb1d4f93ab9e27eb13bb44bec` and reproduces both packaged files.

- extxyz SHA-256: `331b087fc7ced6eaec25fae9dccba767fc47e4ae5e0523fcaddfa4fbf49c455f`
- manifest SHA-256: `c3e189fb8e96a7aec8e587631659f6424fae51cf42243d9f4c54d64e5ed3207d`

The source data are provided by Jan Řezáč and NCI Atlas contributors under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Relevant dataset
papers: [JCTC 2020](https://doi.org/10.1021/acs.jctc.9b01265) and
[PCCP 2022](https://doi.org/10.1039/D2CP01602H).

Upstream states its license in
[`README.md`](https://github.com/Honza-R/NCIAtlas/blob/1816bfc72609d7deb1d4f93ab9e27eb13bb44bec/README.md)
and publishes no `LICENSE` file, so that README is the citable license source.

Subsets drawn from: `HB375x10`, `IHB100x10`, and `D442x10` for the curves file;
`HB375x10`, `D442x10`, and `D1200` for the molecule library.

Modifications: subset selection, single-fragment extraction, and reformatting to
CSV/extxyz; coordinates and energies unchanged.
