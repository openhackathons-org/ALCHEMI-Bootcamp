# Curated NCI Atlas interaction curves

`nci-atlas-curves.csv.gz` is a deterministic, 90-row subset of the
[NCI Atlas](https://github.com/Honza-R/NCIAtlas). It contains ten separation
points and frozen `AB`, `A`, and `B` records for three complexes:

```text
HB375x10    1.041    phenol - N-methylacetamide
D442x10     1.07.74  propyne - methyl azide
IHB100x10   08.007   ammonia - benzoate
```

Each row includes:

- elements, coordinates, fragment identity, and total charge;
- absolute ωB97M-D3(BJ)/def2-TZVPPD energy in kcal/mol;
- CCSD(T)/CBS interaction energy for the corresponding frozen geometry;
- original NCI Atlas gradient-block and geometry-file identifiers.

The source gradient files also contain gradients. They are intentionally not
included because this tutorial evaluates interaction energies only.

```text
SHA-256             7ffbc071e2998cee8e487a2697517187110a05f436920f8611d28d2af5d4d7b7
```

The preparation script verifies all of the following before writing:

- ten scales per complex;
- one dimer and two frozen monomers per scale;
- dimer coordinates match the benchmark geometry;
- monomer coordinates are exact slices of the dimer;
- dimer and fragment charges match the benchmark headers;
- deterministic byte-for-byte output.
