# Mg-MOF-74 structure

`mg-mof-74-primitive.cif` is a 54-atom primitive representation of the
Mg-MOF-74 structure distributed with RASPA2. The checked source cell contains
162 atoms. The local asset applies the R-centered conventional-to-primitive
cell transformation recorded in `manifest.json`; chemical coordinates are
otherwise unchanged.

Source: iRASPA/RASPA2, `structures/mofs/cif/MgMOF-74.cif`, pinned to commit
`fd2398c807e0e0ec4d73c6dd9333539ffb11e98e`. RASPA2 is distributed under the
MIT License. The included structure is used here as a compact porous-material
example for CO₂ adsorption and carbon-capture research.
